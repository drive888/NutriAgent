# 简体中文本地化验收

日期：2026-11-03。用户入口：http://localhost:3103/ 。

## 实现

- 沿用 svelte-i18n，补齐原有中文词条，抽取页面、弹窗、无障碍标签和动态提示中的英文。英文和简体中文共 3,157 个源键，中文缺失及孤立键均为零。
- 内置营养名称、单位全名、默认水瓶名称、统计图例、指标搜索、确认框、连接状态及识别草稿显示均按语言呈现。用户自定义内容保留原文。
- NutriAgent AI 的界面与快捷问题支持中文，系统提示要求回复遵循当前界面语言，保留工具协议与营养安全规则。未改动 AI 服务地址、密钥或模型。
- 服务端依据请求 Accept-Language 或账号已有语言偏好翻译用户可见错误；补充中文邮件与通知模板，保留英文路径和机器错误码。
- 识别预览使用中文字段显示，内部响应 JSON 和营养计算契约保持不变。
- 新增 `npm run i18n:check:zh`，严格检查词条覆盖、ICU 参数、消息语法及 HTML 标签。

- 中文词库严格测试与现有国际化检查通过。识别、标签、业务校验及服务端本地化的重点测试 29 项全部通过。
- 已在真实 3103 页面检查日记、食物库、食物编辑器、识别、目标、统计、健康及 27 个设置页面；食物名称为空时显示“请输入名称”。

## 边界与未验证项

- 历史食物名称、历史聊天、用户自定义餐次和外部食物数据不批量翻译。AI 历史英文回复仍是历史原文；服务商名称、模型 ID、API 字段和标准单位保留必要原文。
- 模型返回的食物名属于识别结果，仍需人工核对；汉化没有提高混合餐识别、估重或营养估算准确率。
- 中文邮件已用模拟 SMTP transport 验证真实模板入口；真实邮件投递、第三方推送、穿戴设备连接及 Android 真机未验收。
- 没有为验收发送新的私人照片或健康记录到外部 AI。公开识别样本只发送到本机适配器。
